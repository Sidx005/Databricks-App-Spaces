# Sample datasets

The demo's sample data is organized into two datasets:

| Dataset | Unity Catalog table | Main fields |
|---|---|---|
| Sales | `workspace.sales_demo.sales_data` | Order/date, region, customer segment, product category, sales channel, revenue, quantity, target |
| Finance | `workspace.finance_demo.finance_data` | Transaction/date, department, expense category, cost center, amount, budget |

The existing [`Tables.md`](../../Tables.md) contains the sample records and screenshots. It is retained as the detailed data reference; this page provides a concise catalog. Dataset content is illustrative and should not be treated as production data.
