# Sample datasets

The demo uses Sales and Finance sample data:

| Dataset | Unity Catalog table | Main fields |
|---|---|---|
| Sales | `workspace.sales_demo.sales_data` | Order/date, region, customer segment, product category, sales channel, revenue, quantity, target |
| Finance | `workspace.finance_demo.finance_data` | Transaction/date, department, expense category, cost center, amount, budget |

The detailed sample records and screenshots are in the [original tables guide](../Tables.md). Dataset content is illustrative and should not be treated as production data.
